calendarEventsCleanup — one-off run, 2026-11-06 (Australia/Adelaide)
====================================================================

What it did
- Reconciled the calendar events written by pushTaskToCalendar against the tasks
  that store their ids. Admin-only, dry run by default, { execute: true } deletes.
- An event was deleted only when eventMatchesTask() agreed: the event's title
  equals the task's title (the 📋 prefix allowed), or its description/body carries
  "TaskBuddy task ID: <task_id>" with that id appearing whole.
- After each successful delete, calendar_synced and calendar_event_id were cleared
  on that task. Flagged tasks with no stored event id (stray flags) were cleared too.

Result — clean: nothing mismatched, nothing errored
- Pass 1, Google, 43 task_ids from backups/calendar-events-index-2026-11-06.json,
  concurrency 2: deleted 43, skipped_mismatch 0, not_found 0, errors 0,
  flags_cleared 44 (the 43 deletes plus the 1 stray flag).
- Pass 2, Outlook, 11 task_ids, concurrency 2: deleted 11, skipped_mismatch 0,
  not_found 0, errors 0, flags_cleared 11.
- Totals: 54 events deleted, 55 task flags cleared.
- Final dry run over all_flagged_tasks: entries_considered 0, stray_flags_found 0,
  would_delete 0. No flagged task remains.

Notes
